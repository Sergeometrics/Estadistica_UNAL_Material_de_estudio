🎯 Módulos Temáticos

📈

Análisis de Regresión

Objetivo: Dominar modelación lineal, inferencia sobre parámetros y diagnósticos.

Tópicos principales

  • Regresión lineal simple y múltiple
  • Estimación insesgada (β₀, β₁, σ²)
  • Varianza de estimadores
  • Intervalos de confianza y pruebas
  • Simulación de cobertura
  • Variables categóricas
📁 Archivos:
  • 1. Mazda_descriptivo.R
  • 3. Insesgamiento_varianza.R
  • 4. Inferencia_sobre_betas.R
  • Tarea_pero_Decente.qmd
🎲

Teoría de Muestreo

Objetivo: Comprender diseños, probabilidades de inclusión y propiedades de estimadores.

Tópicos principales

  • Muestreo Aleatorio Simple (MAS)
  • Probabilidades de inclusión (πᵢ, πᵢⱼ)
  • Estimadores de Horvitz-Thompson
  • Varianza y sesgo
  • Error Cuadrático Medio (MSE)
  • Efecto del Diseño (Deff)
📁 Archivos:
  • cap2.R
  • exercise_2_1.R
  • probability_matrices.R
📊

Análisis Multivariado

Objetivo: Reducción dimensional, agrupamiento y visualización de datos complejos.

Tópicos principales

  • Análisis de Componentes Principales (PCA)
  • Eigenvalores y eigenvectores
  • Análisis de Correspondencias (ACS)
  • Clustering (K-means, jerárquico)
  • Índice Calinski-Harabasz
  • HCPC
📁 Archivos:
  • LABORATORIO_3.Rmd (PCA)
  • LABORATORIO_4.Rmd (ACS)
  • LABORATORIO_5.Rmd (Clustering)
📉

Estadística No Paramétrica

Objetivo: Pruebas de hipótesis sin supuestos distribucionales restrictivos.

Tópicos principales

  • Prueba de Wilcoxon (signed-rank)
  • Prueba U de Mann-Whitney
  • Distribuciones teóricas
  • Comparación paramétrico vs no param.
  • ANOVA y Tukey HSD
  • Pruebas de asimetría
📁 Archivos:
  • Wilcoxon_MannWhitney_v4.R
  • Dev.r

🚀 Inicio Rápido

1

Clonar el repositorio

git clone <repo-url> cd Repo
2

Instalar dependencias

install.packages(c("tidyverse", "FactoMineR", "readxl"))
3

Abrir en RStudio

# Abrir el archivo Repo.Rproj # en RStudio
4

Ejecutar scripts

source("regresion/1. Mazda_descriptivo.R")
